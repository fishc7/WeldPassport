## Назначение

**Работник** (`hr.workers`) — единый реестр физических лиц предприятия.

Человек один. Ролей у человека может быть много. Роли назначаются **поверх**
`worker_id` через таблицу `hr.worker_roles`, без флагов в `hr.workers`.

## Работник ≠ только сварщик

Работник — базовая сущность для:

- сварщиков;
- мастеров / прорабов СМР;
- инженеров ПТО;
- контролёров ОТК;
- специалистов НК;
- инженеров ОГС;
- подтверждающих лиц;
- ответственных за закрытие.

Нельзя создавать отдельные независимые сущности людей (`welders`, `masters`,
`pto_users` как отдельные люди).

## Должность и роль — разные понятия

| Понятие | Таблица | Смысл |
|---|---|---|
| **Должность** | `hr.positions` + `worker.position_id` | кадровая должность по ЕТКС / штатке |
| **Роль** | `hr.worker_roles` | системная / производственная роль в WeldPassport |

## Таблица hr.worker_roles

| Поле | Назначение |
|---|---|
| `worker_id` | FK → `hr.workers.id` |
| `role_code` | код роли |
| `scope_type` | область: GLOBAL, COMPANY, PROJECT, SITE |
| `scope_id` | ID области (null для GLOBAL) |
| `valid_from` / `valid_to` | период действия |
| `is_active` | активна ли роль |
| `note` | комментарий |

### Коды ролей (v0.2)

| role_code | Назначение |
|---|---|
| `WELDER` | сварщик |
| `FOREMAN` | мастер / прораб СМР |
| `PTO_ENGINEER` | инженер ПТО |
| `OTK_INSPECTOR` | контролёр ОТК |
| `NDT_SPECIALIST` | специалист НК |
| `OGS_ENGINEER` | инженер ОГС |
| `CONFIRMING_PERSON` | подтверждающее лицо |
| `CLOSING_RESPONSIBLE` | ответственный за закрытие |

## API

Префикс: `/api/v1/hr`

- `GET /workers/{worker_id}/roles`
- `POST /workers/{worker_id}/roles`
- `PATCH /workers/{worker_id}/roles/{role_id}`
- `POST /workers/{worker_id}/roles/{role_id}/deactivate`
- `POST /workers/{worker_id}/roles/{role_id}/activate`

Карточка работника (`WorkerCard`) включает список `roles`.

Миграция: `backend/migrations/versions/20260703_01_hr_worker_roles.py`

## Что не в hr.workers

В `hr.workers` **нет** полей `is_welder`, `role`, `welder_stamp`, аттестаций и
допусков. Клейма и аттестации — будущий модуль **ОГС / welding**
(`worker_stamps`, `worker_certifications`) со связью `worker_id` → `hr.workers.id`.

## Legacy

Legacy `workforce` (`РАБОТНИКИ`, `СВАРЩИКИ`) **не трогаем** и **не смешиваем**
с новым HR-модулем на этом этапе.

## Следующий этап
